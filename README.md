# Developers Diary Website

A responsive static website for Developers Diary, ready for GitHub Pages.

## Deploy to GitHub Pages

1. Create a GitHub repository named `<your-username>.github.io`.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then **Save**.
6. Wait for the deployment to complete.
7. Open `https://<your-username>.github.io`.

## Before publishing

- Replace the placeholder YouTube URLs in `index.html` with your actual channel/video URLs.
- Replace the placeholder LinkedIn URL with the Developers Diary LinkedIn page.
- Replace the DD favicon/logo if you have a final brand logo.
- Update course/contact links when your paid course is ready.
- If you own a custom domain, configure it from **Settings → Pages → Custom domain**.

## Structure

